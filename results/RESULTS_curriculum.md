# 两阶段课程学习：从"继承数据"到"自我提升"

日期：2026-11-27　设备：RTX 4080 SUPER　Potts q=3，L=16，β=1.2

## 1. 动机

教师模型 `sakura-b6c64h4nbt2tf`（95,876 参数）经过 69 轮闭环训练后卡在一个残余偏差上：

| 指标 | 教师 r61 | 教师 r69 |
|---|---|---|
| 留出集 NLL | 0.14805 | 0.15158（换了参考集，不可直接比） |
| 能量偏差 | **+0.299%（8.1σ）** | **+0.053%（1.0σ）** |
| 能量 TV | 0.0642 | 0.0381 |

r61→r69 这 8 轮里 **NLL 几乎没有改善（只有 1e-5/轮），但物理指标改善了 5 倍**。这说明两件事：

1. **NLL 在极值点附近是平坦的**，对残余分布偏差几乎没有分辨力；
2. **继续训练仍能改善物理质量**，只是无法用 NLL 判断进展。

于是设计的核心问题变成：**如何让一个新模型跳出教师的局部最优？**

## 2. 设计：继承数据，不继承权重

| | 复制权重（`--resume`） | **本方案：继承数据** |
|---|---|---|
| 得到什么 | 教师的参数 | 教师**采样出的构型 + 重要性权重** |
| 上限 | 教师本身（含其偏差） | 理论上是 π 本身 |
| 机制 | 从同一个点继续爬 | 从加权数据**重新推导** q_θ |

**为什么数据重放是合法的**：每个 shard 存的是 `(x, log_rnd)`，而

```
log_rnd = r(x) − log q_old(x) + const = log π(x) − log q_old(x) + const
```

这是 π 的**自归一化重要性权重**——它属于"样本 + 生成它的提议分布"，而不是属于当前模型。只要提议分布覆盖 π，用这些权重做的交叉熵估计就是 π 的无偏估计。**所以离线重放教师的数据在数学上是正确的**，学生继承的是"教师见过的 π 的样本"，而不是教师的偏差。

具体两阶段：

| 阶段 | 数据来源 | 停止条件 |
|---|---|---|
| **Stage 1 warmup** | 教师生成的 24 个 shard（24,576 样本，β=1.2） | 门控分数 ≥ 教师（每 1000 步检查），或跑满上限 |
| **Stage 2 自采样** | 学生自己扫描，4 轮滑动窗口淘汰旧数据 | 无（无限运行，门控持续把关） |

Stage 1 结束时把学生存为 incumbent（旧的 `best.pt` 备份为 `best_prev*.pt`，checkpoint 带 `warmup: true` 标记，重启不会重复 warmup）。

## 3. 结果一：warmup 追不平教师，差距很小

| 步数 | 64ch (b8c64) | 128ch (b8c128) |
|---|---|---|
| 1,000 | −0.59921 | −0.63684 |
| 2,000 | −0.18285 | −0.16892 |
| 4,000 | −0.15178 | −0.15179 |
| 10,000 | −0.15166 | **−0.15164** |
| 教师目标 | −0.15159 | −0.15159 |

**两个模型都没追上，差 5–7e-5**。这不是训练不足（4000 步后曲线完全平了），而是**蒸馏的理论上限**：学生只能学到教师数据所体现的分布，无法通过模仿超过教师。

**128 通道（3.8 倍参数）只多买回 2e-5** ⇒ 这个上限由教师数据决定，与容量无关。

## 4. 结果二：Stage 2 突破教师，且全部指标优于教师

学生 `sakura-b8c64h4nbt2tf-s1024000`（round 24，自采样 24 轮）vs 教师，n=16384 配对评估（同一 SW 参考 −1.89834，噪声 1σ = 3.6e-4）：

| 指标 | 教师 b6c64 r69 | **学生 b8c64 r24** | 判定 |
|---|---|---|---|
| 参数量 | 95,876 | 127,620 | +33% |
| ESS | 0.9765 | **0.9816** | 学生更接近 π |
| 能量偏差 | +1.26e-3（**2.5σ 真偏差**） | **+4.4e-4（1.2σ，噪声内）** | 学生无偏 |
| 能量 TV | 0.0231 | **0.0190（−18%）** | 学生更好 |
| 磁化 TV | 0.0130 | **0.0046（−65%）** | 学生明显更好 |
| 两点关联误差 | 1.1e-3 | **4.0e-4（−64%）** | 学生明显更好 |

**四项全部优于教师**，其中能量这一项的差异是 1.6σ（方向明确），磁化 TV 和关联误差的改善（各约 −65%）更硬。

训练成本对比：

| | warmup | stage 2 | 总计 |
|---|---|---|---|
| 教师 | — | 69 轮 × 4.2 min ≈ 5 h | ≈ 5 h |
| **学生** | 50 min | 24 轮 × 4.2 min = 100 min | **150 min** |

**用 2.2 小时的训练超过了 5 小时的教师。**

## 6. 暴露出的三个方法问题

| 问题 | 实证 | 建议修法 |
|---|---|---|
| **NLL 门控与物理质量脱节** | 教师 r61→r69、学生 r17→r24 都是 NLL 几乎不动而物理指标大幅改善 | 门控改用能量 TV，或 NLL+TV 组合 |
| **ESS 崩塌未被拦截** | r3 在 ESS=0.31 时被晋升 | 加 ESS 否决（从 ≥0.9 崩到 <0.8 就拒绝） |
| **里程碑权重被覆盖** | r17 的权重因 `best.pt` 被 r19 覆盖而永久丢失 | 每次晋升另存 `best_roundNNN.pt`，保留最近 5 份 |

另外：**门控阈值必须随学习率同步衰减**。早期版本只衰减 LR、阈值固定 1e-4，导致衰减后的 LR 只能产生 2e-5 的改进，永远过不了阈值——训练会永久空转（实测连续 8 轮被拒）。现在 `min_improvement` 随 LR 按同一比例衰减（地板 5e-6）。

## 7. 容量扩展与尺寸外推

见 [RESULTS_scaling.md](RESULTS_scaling.md)：

- 128 通道（484.6K）用 **5 轮**达到 64 通道 24 轮的质量，但最终指标相同 ⇒ **容量买速度不买质量**；
- 零样本尺寸外推 **架构上可行**（L=16 → L=24 仍可用，ESS 0.92），但精度随尺寸差退化，且 **128 通道的退化曲线与 64 通道完全相同** ⇒ 容量也不买泛化。

## 8. 复现

```bash
# 1) 从教师生成 warmup 数据（24 shard × 1024 样本，β=1.2）
python scripts/gen_shards.py --ckpt results/weights/teacher_b6c64_round069.pt \
    --n 24 --out data/warmup_teacher

# 2) 两阶段课程训练（自动 warmup → 追平 → 转自采样 + 滑动窗口）
CH=64 BLOCKS=8 \
TEACHER=results/weights/teacher_b6c64_round069.pt \
WARMUP_DIR=data/warmup_teacher \
OUT=runs/potts_L16_b8c64_curriculum \
WARMUP_STEPS=10000 STEPS=800 EVERY=20 \
bash scripts/train_curriculum.sh

# 3) 配对评估（学生与教师必须用同一个 n）
python scripts/eval_checkpoint.py --ckpt runs/potts_L16_b8c64_curriculum/best.pt \
    --beta 1.2 --n 16384 --out results/eval_student
python scripts/eval_checkpoint.py --ckpt results/weights/teacher_b6c64_round069.pt \
    --beta 1.2 --n 16384 --out results/eval_teacher
```
